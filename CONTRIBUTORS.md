---

Want to contribute a signature? Open an issue with the SOFTWARE ID, disk parameters (serial/model/size), and MBR data or key text -- see [command-reference.md](docs/command-reference.md) for how to extract these. Any RouterOS license level (L1-L6) is welcome; the SOFTWARE ID computation and collision search don't depend on `nlevel`.
